Cash Register Management System - Bar La Deportiva

Desktop-based cash register management system developed in C# using .NET, SQLite, and Entity Framework Core. The application was designed to manage daily sales operations for a sports bar environment through a modular and scalable architecture.

The system allows users to register sales, classify payments by cash or card, validate transaction data, generate daily summaries, and calculate end-of-day closing reports. The project was developed following software engineering principles, including layered architecture, separation of concerns, and object-oriented programming practices.

The application structure separates responsibilities into:

  • Models: Sales entity management
  • Data: SQLite database connection and persistence
  • Services: Business logic, validations, queries, and closing operations
  • Program.cs: Main menu and user interaction flow

Features included in the system:

  • Daily sales registration
  • Payment method classification (Cash/Card)
  • Sales validations and error handling
  • Daily sales queries and summaries
  • Automatic total calculations
  • End-of-day closing generation
  • SQLite database persistence

Technologies Used:
C#, .NET, Entity Framework Core, SQLite, Object-Oriented Programming (OOP), Layered Architecture, Visual Studio
